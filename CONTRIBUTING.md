# Contribuyendo a brag-portafolio-template

¡Gracias por tu interés en mejorar este template! Estas son algunas guías para contribuir al proyecto.

## Tipos de contribuciones bienvenidas

- Mejoras a las plantillas existentes (más detalle, mejor estructura, etc.)
- Nuevas plantillas para diferentes tipos de logros o actividades
- Correcciones gramaticales o de estilo
- Mejoras en la documentación o instrucciones
- Traducciones a otros idiomas

## Proceso para contribuir

1. **Fork del repositorio**
   - Crea tu propio fork del repositorio

2. **Crea una rama para tu cambio**
   - Usa nombres descriptivos para tus ramas, por ejemplo: `mejora-plantilla-mensual` o `nueva-plantilla-conferencias`

3. **Haz tus cambios**
   - Realiza los cambios necesarios
   - Asegúrate de seguir el estilo y formato existente
   - Para nuevas plantillas, usa el mismo estilo de las actuales

4. **Prueba tus cambios**
   - Asegúrate de que todos los archivos markdown se renderizan correctamente
   - Verifica que los enlaces funcionan adecuadamente

5. **Envía un Pull Request**
   - Describe claramente qué cambios has realizado y por qué
   - Proporciona contexto sobre el problema que estás solucionando

## Guías de estilo

- Usa markdown estándar para todas las plantillas
- Mantén un estilo consistente con el resto del proyecto
- Para listas, utiliza guiones (`-`) en lugar de asteriscos (`*`)
- Usa encabezados adecuados (H1 para título principal, H2 para secciones, etc.)

## Código de conducta

- Sé respetuoso con todos los contribuidores
- Acepta feedback constructivo
- Enfócate en lo que es mejor para la comunidad
- Muestra empatía hacia otros miembros de la comunidad

¡Gracias por hacer de este template un recurso mejor para todos!
