# brag-portafolio-template

Bienvenido a **brag-portafolio-template**, un repositorio template para documentar y versionar tus logros, proyectos y experiencias a lo largo de tu vida, tanto en el ámbito profesional como personal.

> **Template creado por Cristián Andrée Vera Lyon** - Disponible como plantilla open source para que cualquier persona pueda documentar sus logros profesionales.

## Instrucciones para usar este template

Hay dos formas de usar este template:

### Opción 1: Usar GitHub Template (Recomendado)

1. Haz clic en el botón verde "Use this template" en la parte superior de esta página
2. Elige un nombre para tu repositorio (sugerencia: "my-life-portfolio" o similar)
3. Selecciona si quieres que sea público o privado
4. Haz clic en "Create repository from template"

### Opción 2: Fork del repositorio

1. Haz clic en el botón "Fork" en la parte superior derecha
2. Personaliza el fork según tus necesidades

Una vez que tengas tu copia:

- Actualiza las secciones personales de este README si lo deseas
- Comienza a usar las plantillas en cada carpeta
- Establece una rutina para mantener tu brag document actualizado

## ¿Qué es un Brag Document y por qué mantenerlo?

Un **brag document** (o documento de logros) es un registro personal de tus contribuciones y logros profesionales que te ayuda a:

- **Recordar lo que has logrado**: Documentar pequeñas y grandes victorias que podrías olvidar con el tiempo.
- **Preparar evaluaciones de desempeño**: Contar con evidencia concreta para revisiones, ascensos o cambios de posición.
- **Reflexionar sobre tu carrera**: Identificar patrones, fortalezas y áreas de mejora en tu desarrollo profesional.
- **Impulsar tu confianza**: Visualizar de forma tangible el progreso realizado y los retos superados.
- **Actualizar tu CV o portafolio**: Mantener datos precisos y cuantificables de tus resultados.

## Estructura del Repositorio

- **brag-life-docs/**
  Registro acumulativo de tus logros (brag documents).
  - **monthly/**: Documentos mensuales detallados. Formato recomendado: `YYYY-MM.md` (p.ej., `2023-04.md`).
  - **annual/**: Resúmenes anuales o semestrales que consolidan los hitos y aprendizajes más importantes.

- **projects/**
  Documentación específica de proyectos, con detalles técnicos, contribuciones, impacto y resultados.

- **extras/**
  Otros documentos relevantes como formaciones, charlas, reconocimientos, seguimiento de habilidades, etc.

## Cómo Utilizar Este Repositorio

### Frecuencia de Actualización Recomendada

Para obtener el máximo beneficio, se recomienda:

- **Actualizaciones quincenales**: Dedica 15-30 minutos cada dos semanas para registrar logros recientes.
- **Revisión mensual**: Al final de cada mes, crea un documento mensual completo.
- **Consolidación semestral/anual**: Cada 6-12 meses, elabora un resumen que sintetice los aspectos más relevantes.

### Flujo de Trabajo Sugerido

1. **Registro Continuo:**
   - Mantén notas rápidas de logros en tu herramienta preferida (notas, mensajes, etc.)
   - Programa recordatorios en tu calendario para actualizar tus documentos regularmente

2. **Registro Mensual:**
   - Crea un nuevo documento en `brag-life-docs/monthly/` a partir de la plantilla `template.md`.
   - Nombra el archivo con el formato `YYYY-MM.md` (por ejemplo, `2023-04.md`).
   - Incluye tanto "Quick Wins" como proyectos más importantes.

3. **Resumen Anual:**
   - Al final del año (o cada 6 meses), recopila los hitos más importantes de los documentos mensuales y crea un resumen en `brag-life-docs/annual/` usando la plantilla correspondiente.
   - Analiza patrones, crecimiento y establece metas para el próximo período.

4. **Documentación de Proyectos:**
   - Para cada nuevo proyecto significativo, crea un archivo en `projects/` basándote en la plantilla `projects/template.md`.
   - Actualiza la documentación a medida que el proyecto evoluciona.

5. **Extras y Habilidades:**
   - Utiliza las plantillas específicas en `extras/` para documentar cursos, charlas, premios y habilidades.
   - Actualiza el seguimiento de habilidades trimestralmente.

## Consejos para un Brag Document Efectivo

1. **Sé específico y concreto**: Incluye métricas, datos y resultados cuantificables siempre que sea posible.
2. **Mantén la consistencia**: Establece un ritual regular para actualizar tus documentos.
3. **Incluye logros pequeños**: A veces, los "quick wins" son tan importantes como los grandes proyectos.
4. **Documenta el contexto**: Explica la situación inicial para resaltar el valor de tu contribución.
5. **Guarda evidencias**: Enlaces, capturas de pantalla o referencias que respalden tus logros.
6. **Actualiza en caliente**: Documenta los logros cuando están frescos, antes de olvidar detalles importantes.
7. **Revisa y reflexiona**: Usa estos documentos para análisis periódicos de tu carrera y desarrollo.
